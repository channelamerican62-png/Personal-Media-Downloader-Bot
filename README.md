## 🚀 Ishga tushirish (1 daqiqada):

### 1-qadam: Telegramda Bot ochish
1. Telegramda [@BotFather](https://t.me/BotFather) botiga kiring.
2. `/newbot` buyrug'ini yuboring.
3. Botga nom bering (masalan: `Abdulaziz Media Downloader`).
4. Botga username bering (oxiri `_bot` bilan tugashi kerak, masalan: `abdulaziz_down_bot`).
5. `@BotFather` sizga bergan **API TOKEN** kodini nusxalang (masalan: `7123456789:AAH...`).

### 2-qadam: Tokenni `.env` fayliga yozish
Ushbu papkadagi `.env` faylini oching va tokeningizni yozing:
```env
BOT_TOKEN=7123456789:AAH_sizning_tokeningiz
```

### 3-qadam: Ishga tushirish
Windows kompyuteringizda shunchaki **`start.bat`** faylini 2 marta bosing!

Tamom! Botingizga kirib istalgan YouTube, Instagram yoki TikTok havolasini tashlab, zavqlaning! 👑🔥
